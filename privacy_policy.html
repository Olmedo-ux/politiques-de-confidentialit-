2. Données collectées

Bizibox collecte et traite les données suivantes localement sur votre appareil. Toutes les données sont stockées dans une base de données SQLite locale et ne sont pas transmises automatiquement à un serveur externe.

2.1 Données de produits

Les informations suivantes sont collectées pour chaque produit :

  • Nom du produit
  • Catégorie de produit
  • Prix d'achat (en FCFA ou devise locale)
  • Prix de vente (en FCFA ou devise locale)
  • Quantité en stock
  • Photo du produit (optionnelle, stockée localement)
  • Statut d'archivage (actif/archivé)

2.2 Données de ventes

Pour chaque vente enregistrée, les données suivantes sont collectées :

  • Date et heure de la vente
  • Articles vendus (produit, quantité, prix unitaire, total ligne)
  • Montant total de la vente
  • Montant reçu du client
  • Méthode de paiement (espèces, carte, mobile money, etc.)
  • Client (nom et téléphone) - uniquement pour les ventes à crédit
  • Statut de la vente (active/annulée)

2.3 Données de clients

👤 Données personnelles de clients

Ces données sont collectées uniquement lors de :

  • Ventes à crédit
  • Créances clients
  • Cotisations/épargne
  • Envoi de rappels de paiement

Données collectées :

  • Nom complet du client
  • Numéro de téléphone (format international E164)

2.4 Données de caisse

Pour la gestion des sessions de caisse :

  • Date et heure d'ouverture de session
  • Montant d'ouverture de caisse
  • Date et heure de fermeture de session
  • Montant de fermeture de caisse

2.5 Données de créances et cotisations

Pour le suivi des créances clients et cotisations :

  • Montant total de la créance/cotisation
  • Montant payé
  • Date d'échéance
  • Statut (ouvert, partiel, payé)
  • Historique des paiements
  • Notes et commentaires

2.6 Données de sauvegarde

Lorsque vous exportez une sauvegarde :

  • Copie complète de la base de données SQLite
  • Toutes les données mentionnées ci-dessus
  • Fichier stocké localement ou partagé via votre choix

    4. Partage des données

    4.1 Stockage local uniquement

    Principe fondamental : Toutes les données sont stockées localement sur votre appareil dans une base de données SQLite. Bizibox ne transmet PAS automatiquement vos données à un serveur externe.

    Vos données restent sous votre contrôle total sur votre appareil.

    4.2 Sauvegardes exportées

    📤 Export de sauvegarde

    Lorsque vous exportez une sauvegarde de la base de données :

    • Le fichier est généré dans le stockage local de votre appareil
    • Vous pouvez le partager via l'application de partage de votre choix (email, Google Drive, Dropbox, etc.)
    • Bizibox n'a aucun contrôle sur ces sauvegardes une fois exportées
    • Vous êtes responsable de la sécurisation des sauvegardes exportées

    4.3 WhatsApp (rappels de paiement)

    💬 Intégration WhatsApp

    Lorsque vous envoyez un rappel de paiement via WhatsApp :

    • Bizibox ouvre l'application WhatsApp avec un message pré-rempli
    • Seul le numéro de téléphone et le message sont transmis à WhatsApp
    • Le traitement par WhatsApp est soumis à ses propres conditions de confidentialité
    • Bizibox ne stocke pas les conversations WhatsApp

    Base légale : Consentement explicite de l'utilisateur (action de clic sur le bouton d'envoi).

    4.4 Tiers

    🔒 Aucun partage commercial

    Bizibox ne partage PAS vos données avec des tiers à des fins commerciales. Vos données ne sont jamais vendues, louées ou partagées avec des annonceurs ou des partenaires marketing.

    5. Conservation des données

    5.1 Durée de conservation

    Les données sont conservées sur votre appareil jusqu'à :

    • Leur suppression par l'utilisateur (produit, vente, client individuel)
    • La désinstallation de l'application
    • La suppression des données de l'application via les paramètres de l'appareil

    5.2 Obligations légales de conservation

    ⚠️ Obligations comptables et fiscales

    Certaines données peuvent devoir être conservées plus longtemps pour respecter les obligations légales applicables dans votre juridiction :

    • Historique des ventes : généralement 5 à 10 ans (obligations fiscales)
    • Mouvements de caisse : généralement 5 à 10 ans (obligations comptables)
    • Factures et reçus : généralement 5 à 10 ans (obligations fiscales)

    Responsabilité : En tant qu'utilisateur de Bizibox, vous êtes responsable de respecter les obligations de conservation applicables à votre activité. L'application fournit des outils d'archivage pour vous aider.

    5.3 Archivage

    Bizibox dispose d'une fonction d'archivage pour les produits. Les produits archivés :

    • Ne sont plus affichés dans le catalogue actif
    • Sont conservés dans la base de données pour l'historique
    • Peuvent être restaurés si nécessaire
    • Sont inclus dans les sauvegardes exportées

    6. Vos droits

    Conformément au Règlement Général sur la Protection des Données (RGPD), à la Loi Informatique et Libertés (France), et aux lois applicables sur la protection des données dans votre juridiction, vous disposez des droits suivants :

    6.1 Droit d'accès

    Que vous permet ce droit : Demander l'accès à vos données personnelles.

    Comment l'exercer avec Bizibox :

    • Consultez directement les données dans l'application (produits, ventes, clients)
    • Exportez une sauvegarde de la base de données via le menu "Sauvegarder"
    • Le fichier exporté contient toutes vos données dans un format lisible

    6.2 Droit de rectification

    Que vous permet ce droit : Demander la correction de données inexactes ou incomplètes.

    Comment l'exercer avec Bizibox :

    • Modifiez directement les données dans l'application (produits, clients)
    • Les ventes peuvent être annulées et recréées si nécessaire

    6.3 Droit à l'effacement (droit à l'oubli)

    Que vous permet ce droit : Demander la suppression de vos données personnelles.

    Comment l'exercer avec Bizibox :

    • Supprimez des produits individuels
    • Annulez des ventes (avec conservation de l'historique d'annulation)
    • Supprimez des clients
    • Désinstallez l'application pour supprimer toutes les données

    Limitations : Certaines données peuvent devoir être conservées pour des obligations légales (comptabilité, fiscalité). La suppression définitive peut être limitée si elle compromet l'historique comptable.

    6.4 Droit à la limitation du traitement

    Que vous permet ce droit : Demander la limitation du traitement de vos données.

    Comment l'exercer avec Bizibox :

    • Bizibox traite les données localement et ne les transfère pas vers un serveur
    • Le traitement est déjà limité aux finalités décrites à la section 3
    • Vous pouvez cesser d'utiliser l'application à tout moment

    6.5 Droit d'opposition

    Que vous permet ce droit : Vous opposer au traitement de vos données.

    Comment l'exercer avec Bizibox :

    • Cessez d'utiliser l'application
    • Désinstallez l'application
    • Supprimez les données de l'application via les paramètres de l'appareil

    6.6 Droit à la portabilité

    Que vous permet ce droit : Recevoir vos données dans un format structuré et les transférer à un autre responsable de traitement.

    Comment l'exercer avec Bizibox :

    • Exportez une sauvegarde via le menu "Sauvegarder"
    • Le fichier exporté peut être importé sur un autre appareil utilisant Bizibox
    • Le fichier peut être converti en d'autres formats (CSV, Excel) si nécessaire

    6.7 Droit de retirer le consentement

    Que vous permet ce droit : Retirer votre consentement à tout moment.

    Comment l'exercer avec Bizibox :

    • Allez dans l'écran "Informations légales"
    • Cliquez sur "Retirer le consentement enregistré"
    • Vous devrez accepter à nouveau les conditions pour continuer à utiliser l'application

    7. Sécurité des données

    7.1 Mesures de sécurité mises en place

    Bizibox implémente les mesures de sécurité suivantes pour protéger vos données locales :

    • Stockage local : Données stockées dans une base de données SQLite sur l'appareil
    • Pas de cloud : Aucun transfert automatique vers un serveur externe
    • Export contrôlé : Sauvegardes exportées uniquement sur action explicite de l'utilisateur
    • Permissions minimales : L'application ne demande que les permissions nécessaires (caméra, galerie, fichiers)

    7.2 Responsabilités de l'utilisateur

    ⚠️ Mesures de sécurité à votre charge

    En tant qu'utilisateur, vous êtes responsable de :

    • Sécuriser votre appareil avec un code PIN, mot de passe, empreinte digitale ou reconnaissance faciale
    • Protéger les sauvegardes exportées (chiffrement, stockage sécurisé, ne pas les partager publiquement)
    • Supprimer les sauvegardes lorsqu'elles ne sont plus nécessaires
    • Ne pas partager l'appareil avec des personnes non autorisées
    • Sauvegarder régulièrement les données pour éviter toute perte
    • Respecter les obligations légales de conservation des données comptables et fiscales

    7.3 Limitations de sécurité

    ⚠️ Informations importantes

    • La base de données SQLite n'est pas chiffrée par défaut. En cas de vol ou de root de l'appareil, les données pourraient être accessibles.
    • Les sauvegardes exportées ne sont pas chiffrées. Protégez-les comme des documents sensibles.
    • Bizibox ne peut pas être tenu responsable de pertes de données dues à une mauvaise utilisation ou à un défaut de sécurisation de l'appareil.

    • Les modifications seront notifiées dans l'écran "Informations légales" de l'application
    • La date de mise à jour sera indiquée en haut de cette page
    • En cas de modifications substantielles, un avis sera affiché dans l'application

    9. Protection des mineurs

    Bizibox n'est pas destiné aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de données personnelles d'enfants.

    Si vous êtes parent ou tuteur et que vous savez que votre enfant nous a fourni des données personnelles, veuillez nous contacter immédiatement afin que nous puissions supprimer ces informations.
